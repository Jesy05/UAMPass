Bienvenidos a UAMPass!
------DESCRIPCION-------
UAMPass es una aplicación web desarrollada con ASP.NET Core MVC que permite la gestión de estudiantes y empresas dentro de un portal académico para que estudiantes de la Universidad Americana (UAM) puedan conectarse con 
empresas en busca de oportunidades para pasantes.
 -----Tecnologías utilizadas--------
- ASP.NET Core MVC 7.0
- Entity Framework Core para acceso a base de datos
- SQL Server como motor de base de datos
- Bootstrap 5 para estilos y diseño responsivo
- Razor Views con Tag Helpers
  ------Estructura del proyecto-----
- Controllers/ → Controladores Modelo vista controlador (MVC) (ej. EstudiantesController, EstudianteAuthController): Tienen la lógica principal de cada una de las entidades en c#.
- Models/ → Modelos de datos y ViewModels
- Views/ → Vistas Razor (Login.cshtml, Register.cshtml, Dashboard.cshtml): Contiene archivos .cshtml (convinación entre c# y HTML) para el manejo de la interfaz gráfica.
- wwwroot/ → Archivos estáticos (CSS, JS, imágenes): Contiene archivos css y las imagenes utilizadas para la elaboración gráfica.
  ------Funcionalidades principales----------
- Registro de estudiantes con validación de datos.
- Login seguro con sesiones.
- Recuperación de contraseña (modo demo).
- Dashboard personalizado para estudiantes.
- CRUD completo de estudiantes (crear, editar, eliminar, listar).
- API JSON para pruebas y consumo externo.
